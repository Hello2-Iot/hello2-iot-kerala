# Hello2-IoT: Kerala's #1 Micro-IoT Learning Hub

An interactive STEM & Robotics learning platform engineered specifically for Class 2 to 6 students in Kerala.

## Features
- **ഫ്രണ്ട് പേജ് (Front Page Hero)**: Features real Kerala student innovators with their working IoT Smart Car project ("Smarter Tech for a Safer Tomorrow"), hardware starter kit details, and pocket-money pricing (₹39/month).
- **പ്രോജക്ട് ലാബ് (Project Lab)**: Interactive hands-on projects (P1 to P10), including Magic Auto-Night Lamp, Ultrasonic Obstacle Radar, Talking Plant, and IoT Smart Car. Includes a real-time ambient light physics simulator with an interactive slider.
- **Wokwi ലാബ് (Wokwi Workbench & Code Studio)**: Visual circuit breadboard with interactive pin wiring (click-to-wire, multiple wire colors, 1-Click Auto-Wire), Arduino C++ Code Studio with preset sketches, and a live streaming serial monitor.
- **മലയാളം വീഡിയോകൾ (Malayalam Video Classes)**: Step-by-step video lessons in Malayalam with chapter bookmarks, bilingual audio toggle, and quick lab launchers.
- **കിറ്റ് & പ്ലാൻ (Kit & Plans)**: Detailed breakdown of the 8-component kid-safe hardware starter box, Monthly Pocket-Money Plan, and Super Saver Annual Combo.
- **ലൈവ് ക്ലാസുകൾ (Live Mentorship)**: Weekend workshop batches for Junior Starters (Class 2-3), Robo Explorers (Class 4-5), and Junior IoT Innovators (Class 5-6).
- **FAQ & Quick Order Modal**: Comprehensive answers to parent questions and a streamlined checkout form covering all 14 districts in Kerala.

## How to Run
- Double-click [`index.html`](index.html) to open directly in any browser (Chrome, Edge, Firefox).
- Or run a local HTTP server:
  ```bash
  python -m http.server 3000
  ```
  and visit `http://localhost:3000`.
